# 検証記録

更新日: 2026-09-05

## 現行のカメラプレビュー・Maps Embed 版

現在の変更は、CameraX の背面カメラプレビュー、シャッターから選択済みの過去画像への切り替え、カメラへの復帰、パノラマ ID の保持を対象とします。結果画面の風景は指で操作しない閲覧用の Embed です。GPS と姿勢センサーによる追従、場所の自動認識は対象外です。

実キーを使った Google の認証と、公式サンプルの地点から得たパノラマの描画を Android エミュレーターで確認しました。利用者が選ぶ過去画像の共有リンクからの表示、Google Cloud の実際のキー制限設定と許可外オリジンでの拒否は未確認です。HTML の読み込みや HTTP 200 に加え、実際の画面を確認しています。

撮影年月の取得・独自表示を取り除き、Maps Embed API 用キー1つの構成へ変更しました。`0.2.1`（versionCode 3）で次を確認しました。

- `:app:assembleDebug`、`:app:testDebugUnitTest`、`:app:lintDebug`：成功。Lint はエラーなし、既存の依存更新案内等の警告あり。
- ユニットテスト20件成功（共有 URL 13件、Embed HTML 5件、古いページ通知2件）。年月機能専用のテストは削除。
- 年月表示・metadata 通信・追加キーの BuildConfig 設定をソースから除去。ローカルの認証情報ファイルは変更していない。
- Android 15 / API 35 の専用エミュレーターで、使い方案内、縦横の結果画面の UI 階層に独自の年月表示がないことを確認。
- シャッターで結果画面へ切り替わる際のカメラ切断、「現在に戻る」で再接続を `dumpsys media.camera` で確認。
- デバッグ APK の署名を `apksigner` で確認。

上記の撮影年月削除時の検証では Embed 用の設定値を含むビルドを使用しましたが、キーの有効性や Google の画像表示は判定していません。Google の画像はキャプチャせず、アプリ側の UI 階層とカメラ接続状態を確認しています。証跡は Git 管理外の `artifacts/no-date-*.xml`・`artifacts/no-date-*.txt` に保存しています。変更前の結果は下の旧版記録として保持します。

## 実キーの認証と空白画面の調査

- ローカルの有効なキー設定が空欄ではなく、実行に使用したビルドの値と一致することを確認。キーの値は検証記録へ記載していません。
- `https://appassets.androidplatform.net/` をオリジンとした実キーの Embed リクエストが HTTP 200 を返すことを確認。
- 実際の Android WebView で Google 公式サンプルのパノラマを指定すると、Google の iframe 内に操作 UI が生成され、認証エンドポイントが HTTP 200 を返すことを確認。認証エラーは確認されませんでした。
- 過去の UI テストで使用した `heisei-verification-pano` は実在する画像の ID ではありません。この ID に対する HTTP 400 は、有効な画像を指定していないことによる失敗であり、API キーの認証失敗として扱いません。
- WebView のウィンドウ寸法が約 388 × 491 CSS px でも、ラッパー HTML の `html`・`body` の高さが0となっており、Google のページが読み込まれても画面が空白になる状態を確認しました。WebView の既定の `WRAP_CONTENT` に対し、明示的な `MATCH_PARENT` の指定を追加しています。

修正後は次を確認しました。

- `:app:assembleDebug`・`:app:testDebugUnitTest`・`:app:lintDebug` 成功。既存の20テストはすべて成功。
- Android 15 / API 35、WebView 124 の専用エミュレーターで、共有リンク取り込み → ライブカメラ → シャッター → Street View の画像表示を確認。画像と Google の帰属表示を実際の画面で確認しました。
- 縦画面で約 388 × 491 CSS px、横画面で約 635 × 304 CSS px。ラッパー body と iframe が表示領域全体に広がり、高さが0にならないことを確認。
- 現在のカメラへ戻った際のカメラ再接続、2回目のシャッターでの切断、再表示と回転後の画像表示を確認。
- キーを伏せた DOM・通信・寸法の記録は Git 管理外の `artifacts/auth-*.jsonl` に保存。

公式サンプルは認証・読み込み・描画の切り分け用であり、利用者が選んだ過去画像や平成の最古画像を取得できた証拠ではありません。

今回の確認では Google Cloud の設定画面を変更していません。現在のキーがどの API・オリジンに制限されているか、および許可外のオリジンを拒否するかは未確認です。許可したいオリジンから認証が通ることと、拒否側の制限が機能することは別々に確認します。

## 現行版で確認する項目

1. 初回のカメラ権限要求、拒否時の案内、許可後の背面カメラプレビュー。権限を繰り返し自動要求しないこと。
2. プレビュー開始前にシャッターを押せず、開始後は選択済みの過去画像へ切り替わること。未選択時はリンクの取り込みへ進むこと。
3. 結果画面・バックグラウンドでカメラを使用せず、「戻る」でプレビューを再開すること。
4. API キー未設定の結果画面が設定案内を示し、過去画像を取得したように見せないこと。
5. 最後の有効なパノラマ ID が次回起動に残ること。しおりが画像ファイルやカメラの構図を保存したと表示しないこと。
6. 独自の撮影年月表示や追加 API キーの案内がなく、Google が埋め込み画面に表示する日付・帰属表示を隠していないこと。

## Google 接続の確認項目

1. Maps Embed API のみを許可し、想定する HTTP リファラーを許可したキーで、実画像を表示できること。
2. 許可外のリファラーで Embed リクエストが拒否されること。共通 `appassets.androidplatform.net` オリジンではアプリ固有の識別にならない点を踏まえ、一般配布の構成を確認すること。
3. Google マップで選んだ過去画像の ID が共有リンクに保持され、シャッター後に Embed で同じ画像を表示できること。
4. 結果画面で誤って別の風景へ移動せず、Google のロゴ・帰属表示が縦画面と横画面で遮られないこと。
5. しおりが選んだパノラマを初期表示から再び開くこと。カメラの向き・構図との一致は保証対象にしない。
6. ID が削除・無効化された場合に、別の新しい画像を保存済みの過去画像として扱わないこと。

実機への入力操作・インストール、および Google Cloud のアカウント設定・キー発行はこの記録の検証に含みません。キーと制限の設定方針は [実現性と設計判断](FEASIBILITY.md) を参照してください。

## 撮影年月表示付き Maps Embed 版の記録（参考）

以下は撮影年月の取得・表示を取り除く前の `0.2.0` で確認した内容です。日付機能の削除後の検証結果ではありません。

- `:app:assembleDebug`：成功。バージョン `0.2.0`（versionCode 2）。
- `:app:testDebugUnitTest`：29 件成功（共有 URL 13 件、日付・metadata 8 件、Embed HTML 5 件、古いページ通知・年月状態 3 件）。
- `:app:lintDebug`：エラーなし。依存バージョン・targetSdk の更新案内等の警告あり。
- 最終 APK のデバッグ署名を `apksigner` で検証。エミュレーターから取り出したインストール済み APK とビルド出力の SHA-256 が一致。
- Android 15 / API 35 の専用エミュレーター `emulator-5580` で、カメラの許可・拒否時の表示と背面プレビューを確認。映像はエミュレーターの模擬カメラ入力。
- カメラ拒否状態で再起動しても権限ダイアログを自動再表示しないこと、端末の設定画面から許可するとプレビューが再開することを確認。
- 風景未選択でシャッターを押すとリンク取り込みへ進むことを確認。
- 検証用 ID `heisei-verification-pano` を共有 Intent で取り込み、LIVE 中の選択変更後もシャッターを操作できることを確認。
- シャッターからキー未設定の結果画面へ切り替わり、現在のカメラへ戻ることを確認。`dumpsys media.camera` の Active Camera Clients で、結果画面では切断、復帰後は再接続を確認。
- バックグラウンドでカメラ切断、フォアグラウンド復帰で再接続を確認。
- しおり、画面回転、アプリ終了後の再起動で選択 ID の保持を確認。Google 以外のリンクは拒否し、元の選択を維持。
- 黒・白を基調にグラデーションを加えた最終 UI を縦横で確認。共有で戻ってきた際はリンク取り込みダイアログを閉じる。
- ソース上で写真撮影・録画・ピクセル取得・画像ファイル出力を行っていないこと、GPS と姿勢センサーへの依存を除いたことを確認。

エミュレーター証跡は Git 管理外の `artifacts/` に保存しています。`embed-e2e-results.txt` は機能確認、`instagram-*.png` は最終 UI、`*-camera-*.txt` はカメラ接続状態です。Google の表示や入力抑止を実キーで確認した証跡ではありません。

エミュレーターの描画処理が `swiftshader_indirect` 使用時に一度終了したため、`swiftshader` で再起動して最終 UI を確認しました。アプリのクラッシュログは記録されていません。
