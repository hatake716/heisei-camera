# プライバシーポリシー

更新日: 2026-09-05

平成カメラは、カメラプレビューでシャッターを押すと、現在地付近の Google Street View へ切り替えて眺める Android アプリです。Google マップで選んだ画像の共有リンクを取り込むこともできます。

## カメラと端末の情報

カメラ権限を許可した場合、背面カメラの映像をライブプレビューとして端末内に表示します。シャッターは表示を Street View へ切り替える操作であり、写真撮影・録画・スクリーンショットの保存は行いません。カメラ映像を Google や開発者のサーバーへ送信することもありません。

Street View の結果画面ではカメラの使用を止めます。アプリがバックグラウンドにある間のカメラ撮影は行いません。カメラ権限を拒否した場合はライブプレビューを使用できず、権限を変更する案内を表示します。初回の権限案内を繰り返さないため、案内済みかどうかを端末内に記録します。

姿勢センサーや音声は取得せず、マイク・写真ライブラリーへのアクセス許可は要求しません。Google マップを外部で開いた場合、そのアプリやブラウザーに設定された権限は、それぞれのサービスで扱われます。

## 位置情報

現在地からの自動取得を使うときは、必要に応じて位置情報の許可を求めます。シャッター操作に伴い、アプリを表示している間に GPS・ネットワークから位置を取得し、付近の Street View を表示するために緯度・経度を Google Maps Embed API へ送信します。Google マップでその地点を開く操作でも、表示先のリンクに座標を含めます。

バックグラウンドの位置追跡や移動履歴の記録は行いません。権限がない場合、位置設定が無効な場合、測位できない場合は案内を表示し、再試行や設定変更を促します。カメラ映像から位置を認識する処理はありません。

## リンクとしおり

利用者が共有・貼り付けた Google マップのリンクからパノラマ ID を読み取ります。短縮リンクは Google のサーバーで転送先を確認します。手動で選んだ風景を表示するときは、その ID を Maps Embed API に送信します。カメラ映像から場所や過去画像を検索する処理はありません。

手動で選んだパノラマ ID と、しおりの ID・登録日時などの情報を端末内に保存します。自動取得した結果は、特定の画像のしおりとして保存しません。カメラの向き、画像データ、スクリーンショットは保存しません。旧版のしおりは元のパノラマを開くために保持します。しおりは一覧から削除でき、アプリのデータ消去では最後の選択を含む保存情報が削除されます。

## 外部サービスと WebView

Street View の表示には Android WebView 内の Google Maps Embed API を利用します。Google には自動取得時の緯度・経度、または手動選択時のパノラマ ID のほか、通信に伴う IP アドレス、ブラウザー情報などが送信されます。Google ページや WebView が扱う Cookie・Web ストレージ等は、アプリのしおりとは別のものです。

Google マップやブラウザーを外部で開くこともあります。これらのサービスによる処理には、[Google のプライバシーポリシー](https://policies.google.com/privacy) と [Google マップの利用規約](https://maps.google.com/help/terms_maps/) が適用されます。

アプリ独自の広告配信、アクセス解析、開発者サーバーへの情報送信は実装していません。埋め込み画面に表示される撮影時期、帰属表示、コンテンツや広告は Google が提供します。アプリ独自の撮影年月の取得・表示は行いません。
